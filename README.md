# Lab #5: Models of 3D Objects in WebGL
Each task must depict one of the following objects, depending on the display mode (three modes): 
a dodecahedron, an icosahedron, a sphere, a tetrahedron, an octahedron, a cube, or a pentagonal bipyramid. 
Lighting and rotation of the displayed object around three axes must be provided. Object coordinates must be stored in a database. 
The web application architecture must be implemented using the RESTful approach. 
The client-side component must be implemented using WebGL, and the server-side component must be based on the WebAPI template.
## Task 8
Objects: a sphere, an octahedron, a pentagonal bipyramid.
